# Generate View Layout Visual

## Desktop - Default (Shuffle OFF)

```text
+--------------------------------------------------------------------------------------+
| Generate                                                                              |
+--------------------------------------------------------------------------------------+
| +---------------------------+  +---------------------------------------------------+ |
| | TASK FLOW                 |  | ACTIVE TASK WORKSPACE                             | |
| | Jobs In Progress          |  | Task header, status, match, metadata              | |
| | [shuffle: OFF] [add task] |  |                                                   | |
| | ------------------------- |  | Generation workspace                              | |
| | Task card 01              |  | [CV]  [Generate]  [X]                            | |
| | Task card 02              |  |                                                   | |
| +---------------------------+  +---------------------------------------------------+ |
+--------------------------------------------------------------------------------------+
```

## Desktop - Required Right Mode (Shuffle ON)

```text
+--------------------------------------------------------------------------------------+
| Generate                                                                              |
+--------------------------------------------------------------------------------------+
| +---------------------------------------------------+  +---------------------------+ |
| | ACTIVE TASK WORKSPACE                             |  | TASK FLOW                 | |
| | Task header, status, match, metadata              |  | Jobs In Progress          | |
| |                                                   |  | [shuffle: ON ] [add task] | |
| | Generation workspace                              |  | ------------------------- | |
| | [CV]  [Generate]  [X]                            |  | Task card 01              | |
| |                                                   |  | Task card 02              | |
| +---------------------------------------------------+  +---------------------------+ |
+--------------------------------------------------------------------------------------+
```

## Compact Width (<=1120) - Still Two Column

```text
+----------------------------------------------------------------------------------+
| Generate (Narrow Screen)                                                        |
+----------------------------------------------------------------------------------+
| +----------------------+  +---------------------------------------------------+ |
| | TASK FLOW            |  | ACTIVE TASK WORKSPACE                             | |
| | (fixed left in OFF)  |  |                                                   | |
| | (moves right in ON)  |  | Main generation panel stays visible               | |
| | [shuffle] [add task] |  | while task queue remains side-by-side             | |
| +----------------------+  +---------------------------------------------------+ |
+----------------------------------------------------------------------------------+
```

## Compact Width (<=1120) - Right Mode (Shuffle ON)

```text
+----------------------------------------------------------------------------------+
| Generate (Narrow Screen)                                                        |
+----------------------------------------------------------------------------------+
| +---------------------------------------------------+  +----------------------+ |
| | ACTIVE TASK WORKSPACE                             |  | TASK FLOW            | |
| |                                                   |  | (moved to right)     | |
| | Main generation panel                             |  | [shuffle: ON]        | |
| |                                                   |  | [add task]           | |
| +---------------------------------------------------+  +----------------------+ |
+----------------------------------------------------------------------------------+
```

## Visual Intent

* Shuffle control is in the Task Flow header.
* Shuffle ON places Task Flow on the right for desktop widths.
* At <=1120, layout remains two-column so side-swap is preserved.

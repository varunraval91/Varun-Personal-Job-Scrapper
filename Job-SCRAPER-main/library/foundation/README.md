# Foundation Library — What Goes Where

## cvs/
Drop ALL your CV PDFs here. Any version, any target role.
Examples: cv_sap_2025.pdf, cv_analytics.pdf, my_latest_cv.pdf

## cover_letters/
Drop ALL your cover letter PDFs here.
Examples: cl_sap_btp.pdf, cl_siemens.pdf, cover_letter_operations.pdf

## Naming
No strict naming required. But if you CAN, use this pattern:
  cv_[company-or-domain]_[year].pdf
  cl_[company-or-domain]_[year].pdf

This helps the Smart Selector pick the right samples later.

## What NOT to put here
- Certificates (not useful for generation context)
- Job descriptions (those are fetched automatically)
- Transcripts (unless they contain skill descriptions)

## Why both types?
- CVs teach the AI your STRUCTURE: how you organize sections, which skills you highlight
- Cover letters teach the AI your VOICE: tone, persuasion style, how you frame yourself
- Generating a CV without cover letter context = missing your personality
- Generating a cover letter without CV context = missing your actual skills
